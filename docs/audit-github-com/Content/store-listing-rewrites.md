# ✍️ Pixel Heist — Copy & Store Listing Rewrites

## Short Description / Pitch
Tactical Stealth Infiltration Web Game — sneak through procedurally generated cyberpunk vaults, outsmart 4-state AI guards, pick cylinder locks, and escape with the loot before the security timer expires.

## Key Feature Bullets
- **60 FPS Tactical Stealth Canvas Engine:** Powered by Phaser 3 and Next.js 15.
- **4-State Guard AI & Line-of-Sight Raycasting:** Dynamic polygon field-of-view against procedural walls (`PATROL` → `SUSPICIOUS` → `ALERT` → `CHASE`).
- **Interactive Lockpicking Modal:** Cylinder-pin timing puzzle required to breach secure vaults.
- **HMAC-SHA256 Anti-Cheat Leaderboards:** Cryptographically verified score submissions with deterministic stealth multiplier math (`3.00x` S-Rank).
